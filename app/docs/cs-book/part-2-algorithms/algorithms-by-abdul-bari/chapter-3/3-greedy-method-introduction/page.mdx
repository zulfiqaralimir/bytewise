# 3: Greedy Method — Introduction

---

## What the Greedy Method Is

Think of algorithm design strategies as different lenses a craftsman might reach for, each ground to bring a different kind of problem into focus. The **greedy method** is one such lens — sitting alongside a small family of kindred strategies:

- **Divide and Conquer**
- **Dynamic Programming**
- **Branch and Bound**
- **Greedy Method**

None of these is a single algorithm you memorize and replay — each is a *philosophy*, a way of approaching a problem, that you pick up and apply whenever a problem's shape matches its pattern.

The greedy method, specifically, is the lens reached for when a problem calls out for **optimization** — when the goal is not just *an* answer, but the *best* one.

---

## Core Vocabulary: Feasible, Optimal, and Optimization Problems

These three terms are best understood through a running example: traveling from location **A** to location **B**.

### The problem and its solutions

For any problem, there can be **multiple possible solutions**. For the A-to-B journey, the solutions might be:

- Walk
- Bike
- Car
- Train
- Flight

### Constraints → feasible solutions

A problem usually comes with a **constraint** — for example, "the journey must be completed within 12 hours." Walking or biking might not satisfy that constraint, while taking the train or flight would.

> **Definition:** A **feasible solution** is any solution that satisfies the constraint(s) given in the problem.

Out of all possible solutions, only some will be feasible — the rest simply aren't viable options given the limitations of the problem.

### The objective → optimal solution

Beyond just being feasible, a problem usually has an **objective** — for example, "minimize cost." Among the feasible solutions, exactly one will achieve that objective best (e.g., the cheapest of the feasible options).

> **Definition:** An **optimal solution** is a solution that is both feasible *and* best satisfies the problem's objective (minimum cost, minimum time, maximum value, etc.).

**Important distinction:**

- There can be **many** feasible solutions.
- There can be only **one** optimal solution — because there is only one true minimum (or maximum) value possible.

### Optimization problems

> **Definition:** An **optimization problem** is any problem that requires either a minimum result or a maximum result.

The greedy method — along with dynamic programming and branch and bound — exists specifically to solve this class of problem. Different problems suit different strategies: some fit only one of the three approaches, others can be solved by more than one.

---

## The General Greedy Approach

The greedy method solves a problem **in stages**. At each stage:

1. Consider **one input** from the problem.
2. Check whether that input is **feasible**.
3. If it is feasible, **include it in the solution**.

Repeating this — picking an input, checking feasibility, including it if feasible — across every input eventually produces the optimal solution.

### General algorithm

Picture the input as a labeled array `a`, holding `n = 5` elements:

```
n = 5
a:  [ a1 | a2 | a3 | a4 | a5 ]
      1    2    3    4    5
```

The algorithm below walks across exactly this kind of array — from index `1` to `n` — pulling out one element at a time as its candidate `x`:

```
Algorithm Greedy(a, n)
{
    for i = 1 to n do
    {
        x = Select(a);
        if Feasible(x) then
            Solution = Solution + x;
    }
}
```

Here, `a` is the input array (of size `n`), and the algorithm repeatedly selects a candidate `x` from `a`, tests it with `Feasible(x)`, and adds it to the running `Solution` if it passes.

---

## Intuition: Why It's Called "Greedy"

**Example 1 — Choosing the best car**

One way to find the "best" car is to research *every* brand and *every* model available in the world (or at least your city), compare them all, and only then pick the winner. This is exhaustive — and extremely time-consuming.

In practice, most people don't do this. Instead:

1. Narrow down to a few trusted **brands** (e.g., Toyota, Hyundai).
2. Within those brands, narrow further to the **top models**.
3. Pick the latest, well-tested release from that shortlist.

This selection process — applying your own known filtering method rather than exhaustively evaluating every possibility — **is** the greedy approach. It reliably produces a good result *according to your chosen method*, without the cost of checking every option in existence.

**Example 2 — Hiring from a pool of applicants**

If a company advertises a role and receives a thousand applications, it doesn't give every single candidate every stage of evaluation. Instead, it runs candidates through a sequence of filters — aptitude test, group discussion, technical interview, HR interview — narrowing the pool at each stage until one candidate remains.

That final candidate is the "best" one **according to the selection procedure used** — not necessarily verified against every possible alternative. This is, again, a greedy approach: applying a known, trusted method quickly rather than exhaustively evaluating every candidate against every criterion.

**Think of it like** a series of narrowing funnels: at every stage you commit to whatever passes the current filter, and you never go back to reconsider what got filtered out earlier.

---

## The Big Picture

- The greedy method is one of four major algorithm design **strategies** — a philosophy for approaching a problem, not one fixed algorithm.
- It's the strategy reached for on **optimization problems** — problems that ask for a minimum or maximum result.
- A **feasible solution** satisfies the problem's constraints; there can be many. An **optimal solution** is the one feasible solution that best satisfies the objective; there can be only one.
- The general greedy algorithm walks through the inputs one at a time, tests each with `Feasible(x)`, and adds it to the running `Solution` if it passes.
- It's called "greedy" because it commits to each feasible choice as it's made, using a known selection procedure, instead of exhaustively evaluating every possible combination.

> **Simple takeaway:** the greedy method works by following a known selection procedure at each stage and committing to each feasible choice as it's made — fast and practical, but only guaranteed optimal for problems where that stage-by-stage, never-look-back approach is proven to work.

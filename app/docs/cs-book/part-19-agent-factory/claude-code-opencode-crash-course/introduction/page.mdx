# Claude Code and OpenCode: A Crash Course

*15 Concepts · 80% of Real Use*

## Summary

- **What this is:** A crash course on Claude Code and OpenCode — AI tools that work directly inside your files and terminal, not just in a chat window.
- **Purpose:** Teach the 15 concepts that cover 80% of real day-to-day use, so you move from "AI gives advice" to "AI does the work, correctly, while you watch."
- **Application:** Any workflow built on files, spreadsheets, scripts, or repetitive computer tasks — this isn't limited to software engineers.
- **Why it matters for Investment work:**
  - Automate the repetitive parts of the job — data cleanup, model updates, report formatting — instead of doing them by hand every time.
  - Point an agent at a valuation model, tracker, or dataset and have it pull data, run the numbers, and update the file directly.
  - Build small internal tools — screeners, dashboards, one-off analysis scripts — without waiting on a dedicated engineer.
  - The core skill here, **context engineering**, is what keeps AI-run financial work accurate instead of hallucinated — feeding it exactly the right numbers and rules, nothing more, nothing less.

## What These Tools Actually Do

- Say you have an essay draft — grammar's rough, paragraphs are out of order.
- You tell your computer: fix the grammar, reorder the paragraphs so the argument flows, save the new version.
- It doesn't reply with advice. It opens the file, makes the edits, and saves the result while you watch.
- That's what Claude Code and OpenCode do — AI tools that work directly on your computer. You describe what you want, they do the work, you review the result.

## What This Crash Course Covers

- 15 concepts that cover about 80% of what you'll actually use day to day.
- By the end: what each tool can do, when to use which feature, and how to avoid the common mistakes.

## The One Idea Behind Everything

- Almost every "advanced" technique in these tools comes down to the same move: **giving the AI the right information at the right time, and keeping irrelevant information out.**
- Every section in this course connects back to that idea.
- That idea has a name in the industry: **context engineering** — deciding on purpose what the model sees.

## Three Things to Believe Before You Touch the Tools

- Before any command or setting, three ideas about the AI itself — from Andrej Karpathy (OpenAI co-founder, coined "vibe coding"). Everything in this course rests on them.

**1. It's a ghost, not a person.**
- Keep the "brief it like a colleague" habit from AI Prompting in 2026 — but drop the personhood.
- No ego, no motivation, no memory of yesterday. It won't get offended, get tired, or take initiative you didn't ask for.
- You manage it. It does not manage itself. The rules file, plan mode, hooks — all of it is just ways of managing it.

**2. Its intelligence is jagged.**
- Different models are good at different things (AI Prompting Concept 12) — but a single model is jagged within itself too: superhuman at one task, surprisingly weak at the next, sometimes in the same minute.
- Never assume that because it nailed something hard, it'll nail something easy. Check the easy things too.

**3. Trust it exactly as far as the output can be checked.**
- The closer a task is to checkable — tests pass, the file exists, the numbers add up — the more you can safely hand over.
- Where the output can't be checked, the judgment stays with you.

- Remember #3 especially — it grows into the most important pattern in this course (the verification loop, Concept 10), and from there into two full courses: **Spec-Driven Development** (write the check) and **Loop Engineering** (run it without you).

## Two Tools, One Set of Skills

- This course covers two tools side by side: **Claude Code** (Anthropic) and **OpenCode** (open-source, works with any model).
- Why both: if a technique works in both tools, it's a real skill — not a tool-specific trick. What you learn here transfers between them.

| | Claude Code | OpenCode |
|---|---|---|
| Made by | Anthropic | Open-source community |
| AI models | Claude only | Claude, GPT, Gemini, DeepSeek, local models |
| Best for | Best Claude performance out of the box | Flexibility, cost control, free models |
| Price | Subscription or API | Free models available, or bring your own API key |

- Pick whichever fits your situation — everything in this course works in both.
- **Current as of July 2026.** Both tools update frequently — run `claude update` or `opencode upgrade` before any session. Installation is covered in Section 1 below.

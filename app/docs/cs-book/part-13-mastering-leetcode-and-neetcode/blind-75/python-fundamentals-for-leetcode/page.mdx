# Python Fundamentals for LeetCode

*Blind 75 · Foundations*

---

## Introduction

LeetCode tutorials assume you already know Python's plumbing, then jump straight into algorithms. Let's fix the plumbing first.

---

## Roadmap

| # | Topic | Covers |
|---|-------|--------|
| 1 | [Indentation](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/indentation) | how Python uses whitespace instead of `{ }` to group code |
| 2 | Core Data Types | int/float, str, bool, `None`, mutability vs. immutability |
| 3 | Lists & Slicing | indexing, negative index, `list[a:b:c]`, copying vs. referencing |
| 4 | Dicts & Sets | creation, lookup, `.get()`, membership testing, when to use which |
| 5 | Tuples & Unpacking | tuple packing, multiple assignment, `a, b = b, a` |
| 6 | Loops Deep Dive | `for n in nums`, `range(len())`, `enumerate()`, `zip()`, `while` |
| 7 | Comprehensions | list/dict/set comprehensions, when they help vs. hurt readability |
| 8 | Functions | default args, `*args`/`**kwargs`, `lambda`, return of multiple values |
| 9 | Sorting | `sorted()` vs `.sort()`, `key=`, `lambda` keys, reverse, sorting tuples |
| 10 | Strings | slicing, `.split()`, `.join()`, f-strings, ASCII/`ord()`/`chr()` |
| 11 | `collections` Module | `Counter`, `defaultdict`, `deque`, `OrderedDict` |
| 12 | `heapq` Module | min-heap basics, pushing tuples, simulating a max-heap |
| 13 | Recursion Basics | base case, call stack, recursion vs. iteration tradeoffs |
| 14 | Common Gotchas | mutable default args, shallow vs. deep copy, `[[0]*n]*m` trap |
| 15 | Big-O of Built-ins | cost of list/dict/set ops you'll rely on constantly |

Each topic gets its own deep-dive page, added one at a time.

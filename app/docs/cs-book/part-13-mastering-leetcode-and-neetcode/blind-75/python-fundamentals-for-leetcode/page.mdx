# Python Fundamentals for LeetCode

*Blind 75 · Foundations*

---

## Introduction

LeetCode tutorials assume you already know Python's plumbing, then jump straight into algorithms. Let's fix the plumbing first.

---

## Roadmap

| # | Topic | Covers |
|---|-------|--------|
| 1 | [Indentation](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/indentation) | how Python uses whitespace instead of `{ }` to group code |
| 2 | [While Loops](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/while-loops) | condition-checked loops, infinite loops, `while True` + `break` |
| 3 | [For Loops](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/for-loops) | `for n in nums`, `range()` variations, `enumerate()` |
| 4 | [Lists and Indexing/Slicing](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/lists-and-indexing-slicing) | indexing, negative index, `list[a:b:c]`, in-place vs. new-list ops, two-pointer pattern |
| 5 | [Dictionaries and Hash Maps](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/dictionaries-and-hash-maps) | key-value lookup, `.get()`, `KeyError` trap, the Two Sum hash-map pattern |
| 6 | Core Data Types | int/float, str, bool, `None`, mutability vs. immutability |
| 7 | Tuples & Unpacking | tuple packing, multiple assignment, `a, b = b, a` |
| 8 | Comprehensions | list/dict/set comprehensions, when they help vs. hurt readability |
| 9 | [Functions (def)](/docs/cs-book/part-13-mastering-leetcode-and-neetcode/blind-75/functions) | parameters, `return`, default args, reading LeetCode's `self`/type-hint signatures, multiple return values |
| 10 | Sorting | `sorted()` vs `.sort()`, `key=`, `lambda` keys, reverse, sorting tuples |
| 11 | Strings | slicing, `.split()`, `.join()`, f-strings, ASCII/`ord()`/`chr()` |
| 12 | `collections` Module | `Counter`, `defaultdict`, `deque`, `OrderedDict` |
| 13 | `heapq` Module | min-heap basics, pushing tuples, simulating a max-heap |
| 14 | Recursion Basics | base case, call stack, recursion vs. iteration tradeoffs |
| 15 | Common Gotchas | mutable default args, shallow vs. deep copy, `[[0]*n]*m` trap |
| 16 | Big-O of Built-ins | cost of list/dict/set ops you'll rely on constantly |

# Blind 75 Roadmap

The **Blind 75** is the original curated LeetCode list — compiled by a Facebook engineer and shared on Blind in 2018. It's smaller and older than NeetCode 150, but it's the list that started the "curated list" trend for coding interview prep. If NeetCode 150 is the expanded, pattern-organized version, Blind 75 is the tight, no-filler core.

**75 problems** across **10 topic categories**:

- 🟢 Mostly Easy/Medium, with a handful of Hard problems mixed in
- Covers nearly every core pattern: two pointers, sliding window, DP, graphs, trees, heaps

# How We'll Work Together

Same structured approach as the NeetCode 150 track — for **each problem**:

## 1. Problem Statement
- A clear description of the problem.

## 2. Constraints
- Important limits and conditions to consider.

## 3. Hint (Optional)
- A gentle hint to guide your thinking before viewing the solution.

## 4. Your Attempt
- Space for you to solve the problem on your own.

## 5. Complete Walkthrough

- **Intuition:** Understand the core idea behind the solution.
- **Approach:** Learn the step-by-step algorithm and reasoning.
- **Code (Python):** Write a clean, interview-quality Python solution.
- **Complexity Analysis:** Analyze the **Time Complexity** and **Space Complexity** of the solution.
- **Edge Cases:** Identify and handle inputs that break naive solutions.

> **Problem → Constraints → Hint → Your Attempt → Brute Force → Why It Fails → Intuition → Optimized Approach → Python Code → Complexity Analysis**

# Blind 75 vs. NeetCode 150

| | Blind 75 | NeetCode 150 |
|---|---|---|
| Problem count | 75 | 150 |
| Origin | Facebook engineer, shared on Blind (2018) | NeetCode, expanded from Blind 75 |
| Best for | Tight, high-signal prep in limited time | Deep, pattern-by-pattern mastery |

> **Simple takeaway:** Blind 75 is the fast track — do this first if you're short on time, then expand into NeetCode 150 for deeper pattern coverage.
